01 Brand Philosophy

Terranthro sits at the intersection of two powerful ideas: the timeless authority of cartographic tradition and the analytical precision of modern geospatial data. The aesthetic must honour both equally.

Principle 01
Heritage Meets Signal
Old-world cartographic credibility — serif letterforms, parchment tones, dense spatial information — expressed through a dark, electric medium. The contrast between warm parchment text and deep ink backgrounds echoes the look of maps examined under lamplight.
Never sacrifice readability for atmosphere · Glows are signals, not decoration
Principle 02
Data Is Beautiful
Scientific data — climate statistics, soil types, growing degree days — is the product. Every design decision should make data easier to read and trust, not obscure it. Accent colors are semantically assigned to data categories and must remain consistent across every surface.
Each accent maps to a domain · Never use accent colors arbitrarily · Glows indicate active/live data states
Principle 03
Purposeful Restraint
The dark palette creates an observatory-like environment: the map and its data become the light source, everything else recedes. UI chrome should be near-invisible — thin borders, low-contrast backgrounds — so that content surfaces naturally.
0.5px borders only · Surface layering in 3-step increments · Never use white for backgrounds
Principle 04
Spatial Authority
Every product Terranthro makes is grounded in place. The visual language should reinforce geographic precision: monospaced coordinates, micro-tracked uppercase labels, and data chips that look like instrument readouts rather than generic UI badges.
Coordinates always in mono · Labels always tracked uppercase · AVA / geography always leads in hierarchy
Principle 05
Quiet Confidence
The brand does not shout. Typography is light-weight, spacing is generous, interactions are smooth. The product's authority comes from the quality and depth of its information, not from aggressive visual noise. Animations are subtle and directional — never decorative.
Font weight 300 for body · Animations ≤ 0.3s ease · No drop shadows on type
"Every vineyard block is a data point.
Every data point deserves to be read clearly."

Typography rules
Font pairing intent
Cormorant Garamond carries heritage and emotion. Inter carries information and precision. Never use Inter for decorative headings; never use Cormorant for body copy or data labels.
Weight discipline
Default to light weights (300). Use 400–500 only for headings and emphasis. Never exceed 500. Bold text disrupts the observatory atmosphere.
Line height
Display: 1.0–1.2. Body: 1.7–1.8. UI labels: normal. Generous line-height on body text aids reading dense scientific copy.
Color discipline
Primary headings: parchment. Body copy: muted. Labels and tertiary: ghost. Data values: electric blue or domain accent. Never use full white (#FFF).

06 Surface & Elevation

Depth is created by incremental lightening of backgrounds, not by drop shadows. There are three surface layers plus the special glass treatment for map overlays. Borders are always 0.5px and use --color-border.

--color-ink
Layer 0 — App shell, map canvas background, page body
--color-surface
Layer 1 — Primary panels, sidebars, section backgrounds, modal overlays
--color-surface-raised
Layer 2 — Elevated cards, dropdown menus, hover rows, data chips
glass-card
Layer 3 (special) — Translucent glass treatment for map-overlay cards only. rgba(255,255,255,0.025) bg · rgba(255,255,255,0.07) border
--color-parchment
Map surface cards — solid opaque parchment for on-map controls, popup cards, hover pills that must be legible against any map layer

08 Motion & Animation

Animations reinforce spatial awareness. Panels slide from their origin edge. Content fades up from slightly below. Map fly-to transitions use camera easing. Nothing bounces or pops.

Page / section entrance
0.6s ease
fadeUp — opacity 0→1, translateY 14px→0. Staggers between sibling sections.
Hover glow (buttons)
box-shadow 0.2s
Glow appears on hover only. No scale or background change.
Focus border
border-color 0.2s ease
Input border transitions to electric-blue. No glow ring on focus.
Panel slide-in
0.25s ease
translateX from off-screen edge. Panels never fade in — they slide.
Map fly-to
1.2s MapLibre easing
Smooth camera transition on AVA / vineyard selection. Never instant jump.
Modal / overlay
opacity 0.18s ease
Background scrim fades in. Modal itself fades up with 14px y-offset.
09 Do / Don't
Do
Use 0.5px borders exclusively — never 1px or thicker for structural chrome
Use Cormorant for brand headings and Parchment color for primary text
Apply glows only to active, selected, or live-data states
Maintain semantic color-to-domain consistency across every product
Use Inter 300 weight as the default for all body and UI copy
Let data dominate visually — chrome should recede into the background
Use monospace for all numeric data, coordinates, and values
Maintain parchment (#E8E2D6) as the maximum brightness — never pure white
Don't
Use white (#FFFFFF) anywhere in the UI — parchment is the ceiling
Apply a glow to purely decorative elements or static labels
Use drop shadows — elevation is communicated through background lightness alone
Use accent colors outside their assigned domains (e.g., amber for success)
Use font weights above 500 — no bold text in UI copy
Add animations that bounce, scale, or attract attention to UI chrome
Use Inter for display headings or Cormorant for small labels
Use rounded corners larger than 10px — this is a precision instrument, not a consumer app
